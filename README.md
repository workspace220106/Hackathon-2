# leoparpeix-clone

A rebuild of [leoparpeix.com](https://www.leoparpeix.com/) (Vite + Vue 3 + Three.js + GSAP + Lenis) turned into a
small site: **homepage → login → dashboard**, with the hero's 3D flower replaced by a full-bleed video and a new
colour theme.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173  (the rebuilt, editable site)
npm run build      # production build → dist/
npm run mirror     # http://localhost:5050  (the untouched original site, served from mirror/ + public/)
```

## What's where

| Path | What |
|---|---|
| `src/main.js` | entry: registers GSAP plugins, boots the `App` singleton |
| `src/core/App.js` | app singleton: Lenis smooth scroll, Vue app, asset loading, WebGL, sound |
| `src/core/events.js` | global event bus (`EVENTS`, `emitter`) — every class/component talks through it |
| `src/router/index.js` | routes: `/` (home), `/login`, `/dashboard` (requires login) |
| `src/AppRoot.js` | root Vue component: loader, navbar, cursor, route transitions |
| `src/views/HomeView.js` | homepage sections (header video, hero titles + bee, intro + showreel, project sliders, archives, footer) |
| `src/views/LoginView.vue`, `DashboardView.vue` | the new pages (plain Vue SFCs, styled with the theme) |
| `src/auth/session.js` | demo auth (localStorage) — replace `login()` with your API |
| `src/components/*.js` | the site's UI components (compiled render functions from the original bundle, still fully editable JS) |
| `src/data/home.js`, `src/data/global.js` | **all the copy**: titles, project cards, archives, footer, navbar links, site name |
| `src/webgl/` | Three.js: scenes, cameras, materials/shaders, bee AI (yuka), fluid cursor sim, post-processing |
| `src/webgl/environments/HomeEnvironment.js` | the hero: room model hidden, **`HeroVideoPlane`** sized to fill the camera view |
| `src/webgl/objects/HeroVideoPlane.js` | the video panel (cover-fit) — textured from a canvas fed by `FrameSequence` |
| `src/utils/FrameSequence.js` | plays a folder of numbered JPGs on a canvas (stand-in for `<video>`); `FRAME_CLIPS` lists the hero/loader/guard clips |
| `src/styles/original.css` | the site's stylesheet with the palette swapped (generated by `scripts/apply-theme.mjs`) |
| `public/assets/` | every asset scraped from the original (models, KTX2 textures, fonts, sounds, media) + `medias/frames/{hero,loader,guard}/NNN.jpg` |
| `mirror/` | the original `index.html` + bundle, for side-by-side comparison |
| `docs/research/` | reverse-engineering artefacts (de-minified bundle, identifier map, unit list) |
| `scripts/` | the pipeline that produced `src/` (download → map identifiers → split into modules) |

## Common edits

* **Videos (hero / loader / page transition)** – the mp4s wouldn't decode, so each clip is a JPG frame
  sequence in `public/assets/medias/frames/<clip>/001.jpg…` played by `src/utils/FrameSequence.js`.
  To swap one: export frames (e.g. ezgif "video to JPG"), drop them in the folder named `001.jpg, 002.jpg, …`,
  then set `count` and `fps` (= frames ÷ clip seconds) in `FRAME_CLIPS`. Any aspect ratio works (it cover-fits).
  The scroll zoom is the original camera move: `homeData.header.cameraParams` in `src/data/home.js`
  (`scrollRangePosition.z` = how far the camera pushes in over the header's 200vh).
* **Site name / navbar** – `SITE_TITLE`, `SITE_INFOS`, `NAV_ROUTES` in `src/data/global.js`.
* **Colours** – edit `THEME` in `scripts/apply-theme.mjs`, then `node scripts/apply-theme.mjs`.
  Current palette: yellow `#FFC300` (CTA), sky `#4FC3F7` (blocks), navy `#1B2A4A` (text),
  red-orange `#FF5A2E` (headings), cyan `#00E5D0` (hover), orange `#FFA630` (accent).
* **Projects / archives / footer text** – `src/data/home.js`.
* **Sounds** – `src/config/sounds-manifest.js` (ambient loop, fruit hits, page transition).

## Removed from the original

About and Playground pages (routes, views, components, their 3D scene and textures), the external "Lab" button,
the hero copy ("Driven by detail…"), the daisy sculpture and the studio room in the hero.

## Notes

* `src/.hand-edited` blocks `scripts/split-modules.mjs` from regenerating `src/` (it would overwrite the edits above).
* Canvas playback isn't subject to autoplay policy; the hero clip only pauses/resumes with tab visibility.
* URL flags kept from the original: `?skipLoader`, `?remindScrollY`, `?orbit`.

## Train + soundtrack (2026-09-17)

* The flying bee is now the **Subway Surfers train** (`public/assets/models/global/train/`, loaded by
  `src/webgl/objects/TrainModel.js`, used by `Bee.js` and `Fruits.js`). Size: `TRAIN_LENGTH`.
* Ambient audio is `public/assets/sounds/subway_surfers.mp3` (`src/config/sounds-manifest.js`, `file:` field).
  Volume: `params.volume` there. Sound starts on the first click (browser autoplay rules), toggle with the navbar button.
* **Coins** replace the orange/grapes the train chases: `src/webgl/objects/CoinModel.js`
  (`public/assets/models/global/coin/`), spin speed `COIN_SPIN_SPEED`, size `COIN_SIZE`.
* **Schedule** is a scroll-driven railway timeline (`src/components/ScheduleTimeline.vue`, data from
  `homeData.archives.items`): rails fill in as you scroll, entries alternate sides and light up at the marker.
  On desktop the 3D train leaves its free flight and rides the rails while the section is under the viewport
  centre — the component publishes the marker's screen position in `app.trackBee`, consumed by
  `WebGL._updateTrackBee()` (the old Playground "content bee" slot). Tune `MARKER_AT` / `LIVE_RANGE` in the component.
* **Page transition** (between routes) now plays the guard clip (`FRAME_CLIPS.guard`) inside the
  growing circle instead of the green disc + daisy: `src/webgl/objects/FlowerGroup.js` (`createTransitionVideo`).
* **Graffiti imprints** on the white background: `src/components/ImprintsLayer.vue`
  (`public/assets/imprints/imprint-1..7.webp`, wall backgrounds keyed out by `scripts/cutout-imprints.mjs`).
  They are only placed inside the white sections passed as `zones` (home: hero titles, intro, footer — never over
  the project sliders, the animation section or the archives). Size/rotation in `LAYOUT`, `OPACITY`, `PARALLAX`.
* **Create account** (`/signup`, `src/views/SignupView.vue`) and **Teams** (`/teams`, `src/views/TeamsView.vue`,
  login required). Team cards (name, domain, status, progress bar, expandable problem statement / members /
  mentor / stack / milestones / notes) come from `src/data/teams.js` — swap in your API data with the same shape.
  Cards reveal on scroll (`src/composables/useScrollReveal.js`); the navbar now shows Work · Teams · Login.
